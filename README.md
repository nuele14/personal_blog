# Blog personale

Blog configurato con Jekyll utilizzando il tema [Uno](https://github.com/daleanthony/Uno).

## Citation

Sistema di Bibliografia - [jekyll-scholar](https://github.com/inukshuk/jekyll-scholar)
NB: per il setup è sono stati fatti i seguenti passaggi
- aggiunto jekyll-scholar usando la documentazione ufficiale
- per problemi di compatibilità utilizzata la versione di Ruby 2.7.2
- modificato il Gemfile.lock utilizzando la versione di securerandom 0.3.2 (per problemi di compatibilità con la versione di Ruby)
